# 📦 Order Management System

This is an Angular-based web application that allows users to view, create, and delete recent orders. The interface uses [PrimeNG](https://primeng.org/) components for UI elements and [Font Awesome](https://fontawesome.com/) for icons.

## 🚀 Features

- View a list of recent orders with styling
- Create new orders using a modal dialog
- Delete orders with confirmation prompts
- Responsive design with modern UI components
- Uses Angular reactive bindings and lifecycle management

## 🛠️ Tech Stack

- [Angular](https://angular.io/)
- [PrimeNG](https://primeng.org/)
- [Font Awesome](https://fontawesome.com/)
- TypeScript
- HTML/CSS
